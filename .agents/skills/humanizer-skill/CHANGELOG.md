# Changelog

## 1.0.0 - 2026-11-14

First release.

- `SKILL.md` with four-step workflow (mark, draft, check, deliver), six guardrails, four output modes, and an eight-point self-check.
- 24 numbered patterns in `references/patterns.md`, grouped in six families and ordered by strength.
- `references/voice-and-facts.md` for writing-sample analysis, the ten-item fact-preservation checklist, register notes, and non-English habits.
- `references/search-intent.md` recording the US English keyword snapshot behind the trigger wording, including the rows removed by hand and the intents deliberately excluded.
- `examples/before-after.md` with three complete rewrites and preservation notes.
- Discovery metadata for Claude Code (`.claude-plugin/`), Cursor (`.cursor-plugin/`), OpenAI-compatible agents (`agents/openai.yaml`), and pi-style installers (`package.json`).
- `agent_created: true` in the frontmatter for WorkBuddy skill management; other agents ignore unknown frontmatter fields.
